\section{Certification and Reproducibility}

The structural results of this paper are finite claims about one exact
labeled graph. Their supporting computations are preserved as
machine-readable artifacts. This section records the role of each
certificate family, the logical dependency order, and the boundaries
between direct computation, mathematical deduction, and interpretation.

\subsection{Exact native sources}

All calculations use the exact labeled graph
\[
G_{60}\cong\operatorname{AT4val}[60,6]
\]
with sixty vertices and \(120\) undirected edges.

The full automorphism group is imported from the earlier Project 42
classification and represented as \(480\) explicit permutations of the
same fixed vertex ordering. The principal source is
\[
\texttt{native\_g60\_fiber\_product\_isomorphism\_044.json}.
\]

That certificate supplies:

\begin{enumerate}
    \item the complete native automorphism permutation set;
    \item the explicit correspondence with the fiber-product model;
    \item deterministic row indices for all group elements;
    \item the verified \(230400\)-product multiplication table.
\end{enumerate}

The present paper does not re-enumerate the full automorphism group
from scratch. It uses that already certified permutation group as the
finite ambient group in which the native register is reconstructed.

\subsection{Failed stronger hypotheses}

Three failed stronger hypotheses are preserved explicitly:

\begin{enumerate}
    \item the full conjugation image on the native Klein group is not
    \(S_3\); it is \(C_2\);

    \item the frontier external relay is not \(K_{2,4}\); it is
    \(P_3\sqcup P_3\);

    \item one foreign Klein subgroup does not correspond to one native
    chamber; it corresponds to one pair inside a recovered
    three-chamber block.
\end{enumerate}

Preserving these failures is part of the proof boundary. Each corrected
theorem is stronger epistemically because the larger candidate was
tested and rejected rather than silently omitted.

\subsection{Claim boundaries}

The certificates establish:

\begin{enumerate}
    \item a free normal native Klein action;
    \item a fifteen-chamber quotient isomorphic to \(L(P)\);
    \item four gauge-covariant character operators;
    \item exact cycle holonomy and registered-cycle classes;
    \item fourth-order walk recognition;
    \item foreign Klein stabilizer incidence;
    \item five invariant Petersen matching blocks;
    \item the canonical \(S_5\)-quotient action;
    \item a split extension with sign coupling.
\end{enumerate}

They do not establish:

\begin{enumerate}
    \item a physical interpretation of the character sectors;
    \item that graph-walk moments are physical energies;
    \item that registered closure defines physical mass;
    \item that permutation parity is physical parity;
    \item any claim about forces, spacetime, quantum fields, or
    cosmology;
    \item uniqueness of \(G_{60}\) among graphs sharing only numerical
    fingerprints.
\end{enumerate}

The present paper is a finite structural classification with explicit
receipts.
