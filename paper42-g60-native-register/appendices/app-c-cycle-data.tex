This appendix records the finite cycle counts, holonomy classes,
stabilizers, and relay structures used in the main text.

There are exactly twelve quotient pentagons.

\[

\[

Exactly twenty pair-stabilizer elements preserve the two cycles
separately, and twenty exchange them.

\subsection{External relay structure}

Every frontier cycle carries a six-vertex external relay support.

It contains:

\begin{enumerate}
    \item four cycle endpoints;
    \item two external middle vertices;
    \item four endpoint--middle edges;
    \item no middle--middle edge.
\end{enumerate}

The induced relay graph is
\[
P_3\sqcup P_3.
\]

Each middle vertex supports eight oriented four-step returns, giving
\[
8+8=16.
\]

The two middle vertices lie in one native chamber. Their native
relation is always \(b\) or \(ab\), with profile
\[
b:60,
\qquad
ab:60.
\]

\subsection{Frontier-cycle stabilizers}

The \(120\) frontier cycles form one full automorphism orbit.

Each frontier-cycle stabilizer has order four and is isomorphic to
\(V_4\).

There are exactly fifteen distinct foreign Klein stabilizers.

Each stabilizes eight frontier cycles:
\[
120=15\cdot8.
\]

Distinct foreign Klein groups intersect only in the identity.

Their combined nonidentity element set contains
\[
15\cdot3=45
\]
distinct involutions.

For each foreign subgroup \(H\),
\[
|N_{\operatorname{Aut}(G_{60})}(H)|=32
\]
and
\[
|C_{\operatorname{Aut}(G_{60})}(H)|=16.
\]
