\subsection{Release boundary}

The manuscript source is stored under
\[
\texttt{paper42-g60-native-register/}.
\]

The Overleaf packaging script is
\[
\texttt{scripts/zipit-g60-native-register.sh}.
\]

The generated archive is
\[
\texttt{dist/project42\_g60\_native\_register\_overleaf.zip}.
\]

The archive is a release artifact and is not required to be tracked in
Git. The final release record should include:

\begin{enumerate}
    \item the repository commit containing the completed manuscript;
    \item the SHA-256 digest of the Overleaf archive;
    \item the artifact and script digests;
    \item the archive file listing.
\end{enumerate}

The external release record should be generated only after the
manuscript and verification ledger are finalized, so the archive is
not required to contain its own final digest.
